# Territory handoff implementation

The July 2026 handoff is the product and visual source of truth for this branch.

The rebuilt experience uses a printed-atlas visual language, requires home ground before ordinary play, exposes the next meaningful action in a priority card, resumes unfinished questions after refresh, restricts map operations to legal borders, and provides test-mode action refills so product evaluation never stalls behind the normal daily cadence.

The matching Supabase migrations in this branch have already been applied to the connected production project.
