# Product audit — 2026-08-05

Persona-driven audit and end-to-end Playwright pass of Territory at
`feat/outstanding-work`, run against the local stack with the seeded
Advance Demo League (commish/member) plus disposable signup accounts
(created and removed during the audit). All findings verified in a real
browser at 390×844; scripts live in `tests/e2e/`.

## Findings

### Fixed in this audit

**F1 (P1) — Every auth-surface error was invisible.** The toast element
only rendered inside the signed-in game shell (`territory-game.tsx`),
but the auth, league-entry and lobby branches return before it. Wrong
password, duplicate email, invalid or full invite code: the form just
sat there. Worst case was a new invitee — "Create account and join" with
an existing email did visibly nothing (edge function correctly returned
409; UI swallowed it). Fixed by rendering the toast on every surface
that calls `notify`; regression-verified ("Invalid login credentials" /
"An account with that email already exists. Sign in instead.").

**F2 (P2) — Eight controls under the 44px touch minimum; one real
overlap.** Audited every interactive control at 390px and 360px: zero
horizontal overflow, but auth segments, the league button, map filter
pills, mission-dock CTA, invite copy, league-picker close, and the
runtime logout/advance/end-turn were all under 44px. `.advance` also
kept its desktop offset on narrow screens, sitting on top of the league
button and intercepting its taps. All fixed with minimal
min-height/min-width CSS plus a mobile position for `.advance`;
re-audit green on every screen.

**F3 (P2) — Game chrome floated over full-screen takeovers.** "Log
out", "Advance the day" and the turn banner rendered over the question
arena, result posters and the season-complete panel ("Advance the day"
even stayed active after the season ended). Fixed: chrome hides during
the arena and posters (Report stays, by design) and on a finished
season only Log out remains. Regression-verified on all three surfaces.

### Open — recorded in the backlog

**F4 (P2) — A mid-season joiner's opening move is silently blocked
off-turn.** The dock advertises "OPENING MOVE — Play question", but the
`data-territory-waiting` CSS sets `pointer-events: none; opacity: .42`
on the button while it's someone else's turn, with no explanation. A
brand-new player's first experience is a CTA that doesn't respond.
Either allow the home opening off-turn (it's the player's own state) or
give the dock the same blocked-reason treatment the territory sheet got.

**F5 (P2/P3) — Small map states are untappable on phones.** At 390px
the smallest state paths render at 4×6 to ~30×24 px; the leader-line
labels have `pointer-events: none`; there is no zoom. RI/DE/CT-class
states cannot realistically be attacked or defended by touch. The SVG
paths also carry no aria-labels (nothing for a screen reader). Needs a
design-level fix: hit-area padding, tappable labels, a state list, or
map zoom.

**F6 (P3) — Question bank: 50 of 50 states have exactly one distinct
answer** across their 11 questions (verified by query). Known backlog
item, now quantified: one seen question per state = every future answer
for that state. This remains the biggest gameplay-quality gap; the
defend-reroll cap (B3) limits the worst farming exploit but not the
knowledge leak.

**F7 (P4) — No out-of-app signal for the 24-hour defense window.** Dee
only learns about an attack if the app is open (realtime/poll). A
defender who closes the tab loses by timeout silently. PWA push (P2d)
or at minimum an email would materially change perceived fairness.

**F8 (P5) — Players who own territories cannot be deleted.**
`season_territories.owner_id → profiles` has no cascade/set-null, so
`admin.auth.admin.deleteUser` fails for any player owning a state
(hit live during audit cleanup). Signup rollback (D1) is unaffected —
it deletes before any territory exists — but there is no account
deletion path for a real player mid-season.

**F9 (note) — Post-signup transition is slow in dev.** After a
successful signup the app sat on "Syncing the map" for 6+ seconds
(fresh login later reaches the map in ~0.5s). Likely dev-server compile
latency; re-measure on the hosted deployment before treating it as a
bug.

## End-to-end pass (Playwright, 390×844)

Golden path, all green after the fixes above:

- Auth: sign-in, wrong-password toast, duplicate-email toast, signup →
  joined mid-season with a dealt home state
- Map shell: HUD, filter pills, territory sheet with cost-up-front copy
  ("Attack — 1 move, needs 2+ correct")
- Question arena: live countdown, in-app report dialog (no native
  dialogs anywhere), answer → result poster → return to map
- Attack/defense both directions between two accounts: danger dock
  ("UNDER ATTACK · 23h 59m"), timeout-on-defense poster with
  defense-specific copy ("The clock beat your defense. The attacker
  takes the state."), successful-defense poster, activity feed
  narrating every outcome
- Resilience: LoadErrorScreen on the second failed poll tick with a
  working Retry; blocked `get_my_groups` never leaks LeagueEntry
- Account switch: zero frames render the previous user's
  chip/question/result/toast; per-user saved league; scoped key cleared
  on sign-out
- Season complete: full-screen final standings, no frozen shell
- Touch audit: every control ≥44×44, zero horizontal overflow at 390
  and 360

Suite at audit end: 48 unit / 49 db / 1 smoke, typecheck, build, lint
all green (db suite needs the legacy JWT keys from
`supabase status -o env` and occasionally the documented
`docker restart supabase_kong_HomeTerritory` for the GoTrue flake).

## Addendum — F4 and F5 resolved (same day)

**F4 fixed.** Migration `20260805120000_allow_home_opening_off_turn.sql`
exempts the `home` action from the test-league turn gate in both
`game_begin_action` and the `enforce_test_turn_session` trigger (same
treatment as `defend` — securing home ground touches only the player's
own state and costs no action). The opening dock gets a `missionHome`
class exempting it from the waiting overlay. DB test added
(`tests/db/home-off-turn.test.ts`: off-turn home allowed, off-turn claim
still rejected); browser-verified with a fresh mid-season joiner whose
opening question now opens immediately.

**F5 substantially fixed.** In-map state labels and the right-edge
leader rows are now tap targets that select their state (each leader row
is a full-width 26-unit band), and every state path and leader carries
an aria-label. Browser-verified: tapping the RI leader label opens
Rhode Island's territory sheet. Pinch-zoom and larger in-map labels stay
in the backlog as polish.

**F9 resolved as dev-only.** Subsequent signups reached the map in
~1.0s once the dev server was warm — the original 6s was compile
latency, not an app defect.

## Ship readiness

Code-side, the app is ready for the deploy checklist in
`docs/HANDOFF.md` (owner credentials required: GitHub environment +
secrets, Supabase dashboard, Vercel env, then the D3 `verify_jwt`
check against the hosted gateway). F4 and F5 are the two open items
most likely to hurt a real playtest on phones; F6 is the known
long-pole for replayability.
